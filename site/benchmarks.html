benchmarks

These graphs are drawn from the results the release workflow stores in the repository: the newest release measurement and the newest connections x concurrency sweep. Every figure carries its provenance under it (version, commit, runner, time), and any caveat the stored file justifies is printed in red. All numbers were measured on one self-hosted runner over one unshaped link, so read them as a comparison between easySFTP versions, not as what your server will do. If a graph and the stored JSON disagree, the JSON is right. The data and the commands that redraw each figure are in benchmarks/ and the analysis README.
